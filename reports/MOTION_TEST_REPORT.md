# v1.1 动效更新验证

日期：2026-09-22。本次针对用户反馈的“精选图片无动画、姓名动画太少、详情需要动画”，在原静态结构版上增强动效。

## 已执行的检查

- Astro / TypeScript 检查：0 错误、0 警告，见 check-v1.1.log。
- 动效专项浏览器测试：11 组通过，见 motion-results.json 和 motion.log。
- 生产页面回归：10 组通过，无页面脚本错误，见 browser-results.json 和 browser-v1.1.log。
- 检查与截图均针对生产构建。执行环境为 Linux、Chromium 153.0.8010.0、Playwright 1.58.2。
- 新版没有增加 npm 依赖。客户端动画脚本约 3.7 KB gzip，具体以 build-audit.json 为准；这个数字不代表真实画作的图片下载成本。

## 实际验证内容

1. 首页姓名 13 个字符（含空格）分别创建入场动画，各自延迟不同；辅助阅读仍识别完整姓名。
2. 精选图片滚动入场实际触发；滚动前后纵向偏移值变化，停下时不维持循环计算。
3. 桌面悬停变换实际生效，完整画面缩放至 99%，不裁切或修改色彩。
4. 手动关闭动效后正在播放的脚本动画取消、滚动偏移复位；刷新仍保持关闭。
5. 系统减少动态效果时不创建脚本动画；站内按钮显示“系统关闭”。
6. 详情主图及资料独立入场；故事随阅读进入视野，正常文档流可滚动。
7. 看图模式连续打开/关闭 10 次，包含刚打开就 Esc、中途开启系统减少动态效果；关闭后焦点返回按钮、滚动恢复、画图副本清除。
8. 320、390、760、1024、1440、1920 px 检查动画开始和结束时的布局，均无水平溢出。另有原浏览器回归的 11 档视口及手机横屏检查。
9. JavaScript 关闭时姓名、首页 9 件、列表和详情仍可见；缺少 IntersectionObserver 时精选不隐藏。
10. 首页到总览、详情刷新、前后导航、浏览器返回位置、图片请求失败和 404 均回归；无提前请求高清图。

motion/ 中为新版截图，已查看首页、精选悬停和详情表现。自动化同时观察动画调用、实际变换、操作结束状态；不以静态截图作为动画播放的唯一证据。

## 更新边界

本地根路径测试通过；仓库子路径构建审计结果单独记录在 build-subpath-v1.1.json。没有访问或修改用户 GitHub 权限，用户需要提交并推送更新包，Actions 部署后才会更新线上网站。

Firefox、WebKit、iPhone/Android 真机、正式油画视觉与大陆网络仍未完成验收。原生跨页面淡化由浏览器能力决定，未做跨引擎覆盖；不支持时保持正常链接和详情入场。

未修改作品数据、图片处理逻辑或 GitHub 工作流；v1.0 的内容生命周期证据保留，本次没有重复执行全部内容维护测试。后续提供真实画作仍需单独评审画质和艺术方向。

## 复测

在项目目录运行 `npm run check`、`npm run build`、`npm run test:motion`、`npm run test:browser`。浏览器测试需要先安装 Playwright Chromium 或设置 BROWSER_EXECUTABLE。动效专项使用本机 4323 端口，普通回归使用 4321；没有端口公网暴露。
