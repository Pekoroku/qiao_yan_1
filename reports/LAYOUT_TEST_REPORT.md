# v1.1.1 电脑端排版修复验证

日期：2026-09-22。环境：Node.js 24.19、Playwright 1.58.2、Chromium 153.0.8010.0，本地生产构建。

## 问题与修改

旧版页脚自身使用 `.wrap`，背景被限制在 1920px。2560px 视口下左右各留 320px 纸色边缘；部分短页面没有占满视口，底部也会留白。此次将背景与内容容器分开，并仅在电脑布局中加入页面最小视口高度。页脚仍处于正常文档流，不固定在屏幕上。

首页艺术家区原为左侧独立栏目名、右侧姓名及全部说明。此次在宽度超过 760px 时，将栏目名和姓名放在左栏，简介及入口放在右栏，联系区同步对齐。手机仍使用原来的 DOM 顺序和块级布局。

## 范围

这是本地 Chromium 的 CSS 视口尺寸验证，包含宽屏和全屏大小的视口及高度切换。未直接操作用户 Windows 上的 F11 或浏览器缩放，也不代表真机 Safari / Firefox 或线上部署验收。v1.1 的完整动效验证历史见 `MOTION_TEST_REPORT.md`；本轮仅针对新排版影响的艺术家区动效与页脚交互复测。

运行：先 `npm run build`，再 `npm run test:layout`。若 Chromium 不在 Playwright 默认位置，可用环境变量 `BROWSER_EXECUTABLE` 指定。`--baseline` 只记录旧版布局；`TEST_DIST` 可指定待比较的构建目录。
